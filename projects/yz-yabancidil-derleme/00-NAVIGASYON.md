## 🔄 İŞ AKIŞI (yeni model — yapıştırma YOK)
- **Yerel Claude Code** (PDF'ler + git): yazım/kodlama → `git pull` (başta) · `git push` (sonda).
- **Bulut (cloud)**: web araştırması (DOI teyit, dergi kontrolü) + metodoloji/bütünlük denetimi → aynı depoya pull/push.
- İkisi origin üzerinden senkron. PDF tam-metinleri git'te DEĞİL → yalnız yerelde durur.
